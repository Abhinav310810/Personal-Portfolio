# Full-Stack Personal Portfolio Website

A responsive, database-driven personal portfolio website built from scratch to showcase engineering projects, skills, and contact details. This project was developed as a core requirement for my virtual internship.

---

## 🚀 Key Features
* **Dynamic Project Section**: Fetches and renders project details automatically from a backend database API.
* **Responsive User Interface**: Clean, accessible layout optimized for both desktop and mobile viewing.
* **Full-Stack Architecture**: Separation of frontend presentation layer and backend data processing.

---

## 🛠️ Tech Stack

### Frontend
* **HTML5**: Structured semantic layout.
* **CSS3**: Custom modern styling and responsive grid layouts.
* **JavaScript (ES6)**: Asynchronous Fetch API operations to communicate with the backend.

### Backend & Database
* **Node.js**: Server-side JavaScript runtime environment.
* **Express.js**: Backend routing framework handling API endpoints.
* **MongoDB & Mongoose**: NoSQL cloud database storing project objects securely.

---

## 🔌 API Endpoints Covered
* `GET /api/projects` - Retrieves all portfolio projects stored in the cloud database.
* `POST /api/projects` - Securely inserts new project objects into the database schema.

---

* Designed and established end-to-end full-stack data communication.
* Configured asynchronous JavaScript execution using cloud-hosted environments.
* Structured relational backend data schemas matching frontend visual blocks.
